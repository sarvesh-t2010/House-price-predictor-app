# House-price-predictor-app
This application uses a multiple linear regression model to predict the price of a house from a given dataset based on bedroom count, square feet, bathroom count, and floor count.

**The Algorithm**
- It cleans the data it is given and uses a multiple linear regression model to analyze the data.
- It connects to my app on MIT App Inventor and acts as an API and backend.

**The App itself**
- Features 4 input parameters that the user can input to receive an estimate of the value of their house based on the dataset!
- Provides the user with accurate uptime and response time details of the backend.
